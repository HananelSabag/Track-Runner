# Roadmap

כל אבן דרך מסתיימת במשהו שאפשר להתקין ולהשתמש בו, ב-tag ב-git, ובעדכון של המסמכים הרלוונטיים.

| | אבן דרך | תוצר | מצב |
|---|---|---|---|
| **M0** | מחקר, אפיון, שלד, שדרוג | הריפו הזה | ✅ |
| **M1** | **הקלטה ראשונה** — לוגר + מדידת אמת | אימון אמיתי מוקלט מהשעון שלך | הבא |
| **M2** | שעון MVP — ריצה וכדורגל | שני המצבים עובדים על השעון, עצמאית | |
| **M3** | סנכרון + טלפון MVP | היסטוריה, גרפים וניתוח אימון בטלפון | |
| **M4** | שידור חוזר ומפת חום | המסלול מתנגן על המגרש | |
| **M5** | ליטוש | Tile, שיאים, ייצוא, onboarding | |
| **M6** | Duo (אם יוחלט) | שילוב שעון + טלפון בריצה | |

## M0 · מחקר, אפיון, שלד ✅

- [x] מחקר: פלטפורמה, דיוק, סנכרון, מתחרים, כלים, **כדורגל**
- [x] אפיון מוצר ו-UX, ‏mockups לשני המצבים
- [x] ארכיטקטורה ויומן החלטות
- [x] ריפו + שלד Gradle רב-מודולי
- [x] **שדרוג לגרסאות האחרונות** (AGP 9.4.1, ‏SDK 37, ‏Wear Compose 1.7.1)
- [x] אמולטור Wear OS; האפליקציה הורצה עליו
- [x] מסך "בדיקת מכשיר" בשתי האפליקציות
- [x] לוגו, אייקונים ופלטה (גרסה 2)
- [x] **מנוע הניתוח** (`core:tracking`): אזורי מהירות, זיהוי עבודה/מנוחה, זיהוי ספרינטים, דופק, עוצמה — 33 בדיקות

## M1 · הקלטה ראשונה

המטרה: **אימון אמיתי אחד מוקלט**, כדי להחליף השערות במספרים לפני שמכווננים את המסנן.

- [ ] צימוד השעון ב-Wireless debugging; התקנה; דוח "בדיקת מכשיר" מהשעון האמיתי
- [ ] הרשאות (מיקום, זיהוי פעילות, דופק) עם הסברים
- [ ] `SpeedSource`: ‏GNSS ישיר + Health Services, מוקלטים במקביל
- [ ] foreground service שמקליט ל-Room, עם Ongoing Activity
- [ ] מסך הקלטה מינימלי: התחל / מהירות חיה / סיום
- [ ] ייצוא ההקלטה לקובץ ומשיכה שלה למחשב
- [ ] **הרצת ההקלטה דרך מנוע הניתוח** — לראות אם זיהוי המנוחה והספרינטים תואם למה שקרה באמת
- [ ] מדידת סוללה לכל מקור
- [ ] ארבעת ניסויי הדיוק מ-[02](research/02-speed-accuracy.md#6-תוכנית-האימות-שלב-m1)
- [ ] **הכרעה:** מקור ראשי, פרמטרי המסנן, וכיוונון ספי המנוחה

**דורש ממך:** צימוד חד-פעמי של השעון, ואימון אחד איתו (ריצה או כדורגל).

## M2 · שעון MVP — ריצה וכדורגל

- [ ] `SpeedFilter` (Kalman), עם בדיקות הרצה-חוזרת מההקלטות של M1
- [ ] בחירת מצב במסך "מוכן"
- [ ] **ריצה:** מסך חי, פקדים, סיכום
- [ ] **כדורגל:** מסכי עבודה / ספרינט / מנוחה, סיכום עם עבודה-מנוחה
- [ ] ניתוח חי: המנוע רץ על האימון תוך כדי הקלטה
- [ ] רטט: כניסה לעבודה, ספרינט, שיא חדש
- [ ] היסטוריה והגדרות על השעון (יחידות, סף מנוחה, גיל/דופק מרבי)
- [ ] מצב Ambient
- [ ] שחזור אחרי קריסה
- [ ] אזורים אישיים: חישוב המהירות המרבית שלך מהאימונים האחרונים

**בסוף M2:** אפשר לצאת לאימון עם השעון בלבד ולקבל את כל הניתוח עליו.

## M3 · סנכרון + טלפון MVP

- [ ] `core:sync`: מעטפה, קידוד, round-trip
- [ ] `SyncEngine` בשעון, `SyncReceiver` בטלפון, אישורים ופיוס
- [ ] היסטוריה משותפת לריצות ולאימוני כדורגל
- [ ] מסך ריצה: גרף מהירות + טבלת דקה-דקה
- [ ] מסך כדורגל: ציר עבודה/מנוחה, אזורים, רשימת ספרינטים, דופק והתאוששות
- [ ] בדיקות: אימון בלי טלפון → חזרה לטווח; ניתוק באמצע העברה; התקנה מחדש

## M4 · שידור חוזר ומפת חום

## M6 · Duo (אם יוחלט)

שילוב GNSS של הטלפון בריצה, החלקה בדיעבד ממוזגת, ומדידה אם זה באמת משפר.

## אחר כך (לפי עניין)

זיהוי פרצים ממד התאוצה (האצות, שינויי כיוון) · Health Connect · חיישנים חיצוניים (רצועת דופק, GNSS של 10Hz) · Live Updates ל-Wear OS 7.

## שיטת עבודה

- **ענף `main` תמיד נבנה.** commit אחד לכל יחידת עבודה שלמה, עם גוף שמסביר למה.
- **tag מוער לכל אבן דרך** ואחר כך לכל גרסה.
- **מסמכים מתעדכנים באותו commit** שמשנה את מה שהם מתארים.
- **החלטות כבדות** נכנסות ל-[decisions.md](architecture/decisions.md) לפני שמיישמים אותן.
